Works with the MCP server your analytics agent already uses

Add it to honest_agent_config.yml with a URL or a local command, and pick the model your agent runs on. One target per agent, like a dbt profile.

honest-agent
Any model
Anthropic or OpenAI
honest_agent_config.yml
default_target: motherducktargets: motherduck: mcp_url: https://api.motherduck.com/mcp bearer_token_env: MOTHERDUCK_TOKEN model: claude-sonnet-4-5
default_target: snowflaketargets: snowflake: mcp_url: https://<account>.snowflakecomputing.com/api/v2/databases/<db>/schemas/<schema>/mcp-servers/<server> bearer_token_env: SNOWFLAKE_MCP_TOKEN model: claude-sonnet-4-5
default_target: sales-agenttargets: sales-agent: mcp_url: https://mcp.yourcompany.com/mcp bearer_token_env: MCP_TOKEN model: claude-sonnet-4-5
default_target: demotargets: demo: mcp_command: uv run python -m honest_agent.demo_server warehouse.duckdb default_database: warehouse default_schema: main model: claude-sonnet-4-5
$ honest-agent run --target motherduck
$ honest-agent run --target snowflake
$ honest-agent run --target sales-agent
$ honest-agent run --target demo
