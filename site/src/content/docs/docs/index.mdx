honest-agent tests an AI analytics agent the way you'd test code: with questions you
already know the answers to. Run them every day, and you find out when your agent starts
getting things wrong, before your team acts on a wrong number.

## What it checks

Every eval checks two things about the agent's answer:

- **Accuracy:** is the answer right? honest-agent compares it with the answer you wrote
  in the eval.
- **Provenance:** did the answer come from the right place? honest-agent checks that the
  agent's SQL read the tables your team trusts for that question.

An answer can be right by luck, from the wrong table. Provenance catches that; accuracy
catches a wrong number from the right table. Each eval has a threshold for both.

## How a run works

<HowItWorks />

1. You write evals: a question, its right answer, and the tables it should come from.
2. honest-agent asks each question with the model you choose, using the tools from your
   agent's own MCP server: the same tools your team's agent uses.
3. It grades every answer for accuracy and provenance, and stores the results with
   everything the agent sent and received.
4. The report shows the scores over time and why each eval passed or failed. A Slack
   alert tells your team when one falls below its threshold.

honest-agent refuses SQL that would change your data before it reaches your MCP server.
It can only check SQL, though, so give the server
[read-only credentials](/docs/getting-started/#4-fill-in-env) too.
